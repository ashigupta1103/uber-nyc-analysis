# 🚕 Uber NYC Pickup Data Analysis

A major data science project analyzing patterns in Uber pickups across NYC using the Kaggle dataset.

## 🔍 Objectives

- Analyze temporal trends in Uber pickups
- Perform EDA with visualizations
- Build predictive ML models to estimate pickup demand

## 📁 Dataset

- Uber NYC pickups from [Kaggle](https://www.kaggle.com/datasets/fivethirtyeight/uber-pickups-in-new-york-city)

## 📊 Techniques Used

- Data Cleaning & Merging
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Machine Learning Models: Linear Regression, Random Forest Regressor
- Performance Evaluation with RMSE & R² Score

## 📈 Results

- Evening and weekend hours show the highest demand
- Random Forest Regressor achieved better accuracy than Linear Regression

## 🛠 Libraries Used

- pandas
- matplotlib
- seaborn
- scikit-learn

## 📌 Conclusion

This project demonstrates how data-driven decisions can help ride-sharing platforms improve services, allocate drivers better, and predict demand surges effectively.
